# [보고서] 딥러닝 학습 안정화 및 하이퍼파라미터 최적화 실험 프로젝트 결과 보고

** 기본 필수 **

## 1. 개요

* **목적**: PyTorch 프레임워크 기반의 인공신경망(ANN) 구조에서 최적화 알고리즘(AdamW)의 학습률(Learning Rate) 변화에 따른 모델의 학습 안정성을 진단합니다. 동일 조건 하에서 Baseline과 비교군의 성능 변화 추이를 정량적으로 평가하여 최적의 하이퍼파라미터 실행 계획을 수립하는 것을 목적으로 합니다. 

* **주요 방법론**:
    * 데이터 누수(Data Leakage)를 원천 차단하기 위해 격리된 Train(12건) 및 Validation(4건) 세트를 기반으로 실험을 수행합니다.
    * 최적화 도구로 AdamW 알고리즘을 사용하며, 규제화를 위한 weight_decay는 0.0으로 고정합니다.
    * 학습 지표로 CrossEntropyLoss(크로스 엔트로피 손실 함수)를 채택하여 에포크(Epoch)별 오차 추이를 추적합니다.

* **결과 요약**: 두 학습률 후보(lr=0.001, lr=0.01) 모두 1 에포크만에 손실값 0에 도달하여 극심한 과적합(Overfitting) 징후를 나타냈습니다.

## 2. 실험 및 모델 비교 결과

동일한 모델 구조와 고정된 재현성 시드(seed = 42, Epoch=20)하에서 두 가지 학습률(Learning Rate) 대안의 검증 성능을 비교했습니다.

* **비교 대안**:
    1. `baseline` : 기본 설정 학습률(`lr=0.001`)
    2. `candidate` : 가속 학습률 후보(`lr=0.01`)
* 평가 지표: 최소 검증 손실값(`best_valid_loss`) 및 해당 시점의 에포크(`best_epoch`)

| 실험 세팅 (Setting) | 학습률 (lr) | 최적 에포크 (best_epoch) | 최소 검증 손실(best_valid_loss) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **baseline** | *0.001* | *1* | 0.0 | 기준 모델 |
| **candidate** | *0.010* | *1* | 0.0 | 비교 후보군 |

## 3. 모델 선정 및 설정(Selected Plan)

실험표 결과를 바탕으로 최종 선정된 모델 실행 계획 및 파라미터 상태입니다.

* 선택된 모델 구조: Linear(2, 8) -> ReLU() -> Linear(8,2) 구조의 인공신경망(ANN)
* 최종 선정 파라미터: lr = 0.001 (baseline)
=> 선정 사유: 두 대안 모두 최소 검증 손실이 0.0으로 동일하게 수렴하였으나, 하이퍼파라미터 튜닝의 안정성 측면에서 급격한 발산 위험이 적은 보수적인 기본 학습률(lr=0.001)을 기준으로 채택함.


## 4. 선정 모델의 결과 흐름 진단

출력된 history 및 가상 평가 기록 분석 결과는 다음과 같습니다.

• 손실값 기록 패턴 및 현상 관찰:
	• 학습률 0.001과 0.01 집단 모두에서 첫 번째 에포크 이후 검증 손실값(valid_loss)이 0.0으로 완전히 떨어져 계속 유지되는 현상이 확인됨.
	• 훈련 오차와 검증 오차가 동시에 지나치게 이른 시점에 영(0)에 수렴하는 현상은 정상적인 일반화 과정을 벗어난 극심한 과적합(Overfitting) 상태임을 시사함.


## 5. 향후 계획 및 제언(Next Steps)
1. 데이터 표본 확대 및 불균형 해소: 현재 사용된 전체 데이터 표본 수(n=20)가 딥러닝 모델이 일반적인 패턴을 학습하기에 턱없이 부족함. 충분한 수의 표본 데이터를 추가로 확보하여 모델의 학습 다양성을 보장해야 함.
2. 규제화 메커니즘 도입: 과적합을 억제하고 데이터의 트렌드를 둔감하게 학습할 수 있도록 가중치 감쇠(weight_decay > 0) 옵션을 활성화하거나 가중치 중간값을 정제하는 규제 기법 도입이 필수적임.
3. 평가 모드 데이터 바인딩 정상화: 코드 내 검증 루프 구현 시 valid_loss 기록 부문의 하드코딩 요소를 제거하고 실제 검증 세트(X_valid, y_valid)의 손실 추이가 온전하게 반영되도록 파이프라인 보완이 필요함.

** 응용 **
## 1. 개요
* **목적**: Pytorch 프레임워크를 활용하여 인공신경망(ANN)의 최적화 알고리즘(SGD, AdamW) 및 규제화 기법(Dropout) 변화에 따른 다중 조건 실험을 수행합니다. 미니배치 데이터 로더 환경에서 검증 손실(Valid Loss)을 모니터링하고, 가중치 최적 상태(Best State)를 보관/복원하여 모델의 일반화 성능과 클래스별 재현율(Recall)을 평가하는 것을 목적으로 합니다. 

* **주요 방법론:** 
  * 입력층, 은닉층(Width=32), 활성화 함수(ReLU), 출력층으로 구성된 모델 구조에 Dropout 비율(0.0, 0.3)을 다르게 적용합니다.
  * 에포크 종료 후 모델을 eval 모드로 전환하여 평가하고, copy.deepcopy를 통해 최적의 가중치 스냅샷을 안전하게 보관 및 복원 합니다.
  * 불균형 평가를 보완하기 위해 각 클래스(0, 1)별 실제 표본 수(support) 대비 정답 수 (correct)를 기반으로 개별 Recall을 추출합니다.
* 결과 요약: 총 3가지 조건 실험을 수행한 결과, 규제화가 없는 AdamW 알고리즘 세팅이 가장 낮은 손실값과 높은 안정성을 보이며 최적의 파라미터로 선정되었습니다.

  * **선택된 모델 유형 및 최적 파라미터:** `AdamW` (학습률 lr=0.01, Dropout=0.0)

    * **모델 구조:** `Linear(2, 32) -> ReLU -> Dropout -> Linear(32, 32) -> ReLU -> Dropout -> Linear(32, 2)` 구조의 다층 인공신경망
    * **미니배치 구성:** `batch_size=32`, `shuffle=True` (매 후보마다 시드 43번 기반의 동일 셔플 순서 보장)
